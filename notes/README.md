# Notes: explain it your way

A lesson gives one explanation. Often a second view makes it click. This folder is for **your** explanation of any concept, with a real-time example. Several notes about the same concept are welcome: each person sees it differently.

You only need to write text. No programming.

## Add a note in four steps

1. Copy [TEMPLATE.md](TEMPLATE.md) into the folder of the subject (create the folder if it is missing): `sdlc`, `linux`, `git`, `github`, `cicd`, `jenkins`, `docker`, `kubernetes`, `ansible`, `terraform`, `aws`, `observability`, `devsecops`.
2. Name it after the concept and you: `aws/s3-buckets-by-ravi.md`. Small letters, hyphens, no spaces.
3. Fill it in. Leave out parts you do not need, but keep **In one sentence** and **Real-time example**.
4. Add a line to the list below, then send it (see "Contribute" in [PROJECT.md](../PROJECT.md#10-contribute)).

## What makes a note useful

- Start from something everyone knows: a kitchen, a post office, a bus.
- Tell a small story: who, what problem, what changed, what result.
- Say where your comparison stops being true.
- Short sentences. Explain a difficult word the first time.
- Your own words and your own example. No copied text, no real company secrets, no passwords or private names.
- Check facts with the official documentation and link it.
