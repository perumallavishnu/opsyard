## Parts of GitHub
# c-ghrepo | Repository page and README | Beginner | The front door of a project.
@@ user Visitor ; doc README ; db Code ; shield Licence
= Without it | PROBLEM
" a How do I start this?
A stranger finds code and cannot tell what it does or whether it may be used.
= What it is | SOLUTION
Each repository has a page. **README** explains, **LICENSE** permits, **CONTRIBUTING** guides, **SECURITY** tells how to report a problem.
= How it works
Public: everyone can read. Private: only people you invite. Roles: read, triage, write, maintain, admin.
= Real-time example | PRACTICE
A company publishes a library. Good README and licence bring 200 users and 15 fixes from outside.
? No licence file means... | free to use | *no clear permission to use | public domain

# c-issues | Issues and Projects | Beginner | Work lists beside the code.
@@ user User ; card Issue ; team Dev team ; board Project
= Without them | PROBLEM
Bug reports come by chat and are forgotten.
= What they are | SOLUTION
An **issue** is a discussion about one bug or idea. A **Project** is a board or table of issues.
= How it works
Labels, assignees, milestones, templates. Writing `Closes #42` in a pull request closes the issue on merge.
= Real-time example | PRACTICE
A five-person start-up plans everything in Projects. A 200-person company uses Jira and links it to GitHub.
? What closes an issue on merge? | A label | *The word Closes with its number | A star

# c-fork | Fork, star, watch | Beginner | Taking part in someone else's project.
@@ user You ; db Your fork ; db Their project ; user Maintainer
= Without it | PROBLEM
You found a bug in a tool but may not write to its repository.
= What it is | SOLUTION
A **fork** is your own copy on GitHub. You change it and offer the change back by pull request.
= How it works
Fork, clone, branch, push, open pull request. The maintainer reviews. **Star** is a bookmark, **watch** sends news.
= Real-time example | PRACTICE
A student fixes a spelling error in documentation: a first open source contribution in ten minutes.
? Contribute without write access by... | email | *fork and pull request | star

# c-ghsecret | Secrets, variables, environments | Intermediate | Settings for automation.
@@ user Admin ; key Secret ; gear Workflow ; gate Environment
= Without them | PROBLEM
A token is written in the workflow file and everyone can read it.
= What they are | SOLUTION
**Secrets** are encrypted and hidden in logs. **Variables** are plain settings. **Environments** hold both and can demand approval.
= How it works
`${{ secrets.NPM_TOKEN }}` is filled in at run time. Fork pull requests normally get no secrets.
= Real-time example | PRACTICE
Deploying to `production` waits for one of two named people to approve.
? Approval before production belongs to... | a label | *an environment | a fork
