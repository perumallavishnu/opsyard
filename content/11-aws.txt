= What cloud means
+ u

= Regions and zones
+ r a b c

* app
AWS secures the cloud: buildings, hardware, managed service software. You secure what is **in** it: data, access, configuration, guest OS on EC2.

= Root | RISK
+ u
: u err root
The root user can do everything. Turn on MFA, make no access keys, use it almost never.
= Policies
A policy is JSON: which actions, on which resources, under which conditions. It is attached to a user, group, role or resource.
+ p ev s
~ u>ev GetObject? ;; ev>p check ;; ev>s allow
> { "Effect": "Allow", "Action": "s3:GetObject",
>   "Resource": "arn:aws:s3:::acme-logs/*" }
= How it decides
* ev
Everything is denied by default. An explicit **Allow** permits. An explicit **Deny** always wins.
= Roles
+ ro ec
~ ec>ro assume ;; ro>ev temporary keys
A role gives temporary credentials. Attach roles to EC2, Lambda or pods instead of storing access keys.
= People
~ u>ro sign in
Use IAM Identity Center with your company login. Avoid long-lived IAM user keys.
= Least privilege | PRACTICE
* p
Start narrow. IAM Access Analyzer can suggest policies from real use. Organizations add **SCPs** as guardrails across accounts.
? Allow and Deny both match. Result? | Allow | *Deny | Depends on order

# aws-vpc | VPC networking | Intermediate | Subnets, routes, gateways and firewalls.
Z v 1 0 3 2 VPC 10.0.0.0/16

@ gw gate 1 0 Internet gateway
@ lb router 2 0 Load balancer

@ app server 3 0 App (private)
@ db db 3 1 DB (private)
= A private network
+ v
A VPC is your own network in a Region. Split it into subnets; each subnet lives in one zone.
= Public subnet
+ i gw lb
~ i>gw ;; gw>lb
A subnet is public when its route table sends `0.0.0.0/0` to an **internet gateway**.
= Private subnet
+ app db
~ lb>app ;; app>db
Apps and databases have no route from the internet.
= Going out
+ nat
~ app>nat updates ;; nat>gw
A NAT gateway lets private machines start connections out. It costs per hour and per GB; a gateway endpoint for S3 avoids much of it.
= Security groups and NACLs
* app db
: db ok from app only
**Security groups** are stateful, allow-only, on the interface. **Network ACLs** are stateless, on the subnet, with allow and deny.
= Connecting networks
* v
Peering (two VPCs), Transit Gateway (many), PrivateLink (one service privately), VPN or Direct Connect (your office).
? What makes a subnet public? | Its name | *A route to an internet gateway | A security group

= An instance
+ a
Choose an **AMI** (disk image), **instance type** such as `t4g.small`, subnet, security group and IAM role. User data runs at first boot.
= Connect
* a
Session Manager gives a shell with no open SSH port and records it.
= Load balancer
+ u lb b
~ u>lb ;; lb>a ;; lb>b
**ALB** works with HTTP paths and hosts. **NLB** with TCP and UDP at very high rates. Health checks remove bad targets.
= Auto Scaling
+ asg cw
~ cw>asg CPU 80% ;; asg>b add
Keeps the group between min and max and replaces unhealthy instances. Target tracking: "keep CPU near 50%".
= Paying
On-Demand is flexible. Savings Plans commit for a discount. **Spot** is far cheaper and can be taken back with two minutes' notice.
= Lambda or EC2?
* a
Before running servers, ask whether a managed service fits.

+ app s3

= EBS
+ ebs

+ efs

A Linux file system many instances mount together.

+ gl
~ s3>gl after 90 days
Rules move old objects to cheaper classes or delete them. Cheaper classes can have retrieval fees and delays.
= Keep it private | RISK
* s3
: s3 ok blocked public
Block Public Access is on for new buckets. Share with pre-signed URLs or CloudFront. Versioning and Object Lock protect against deletion.

= No servers to run
+ u g l d
~ u>g ;; g>l ;; l>d
Code runs on a request and you pay per use. Nothing runs when nobody calls.
= Scaling
+ l2
~ g>l ;; g>l2

A new environment takes time to start. Smaller packages help; provisioned concurrency removes it for a price.

+ s

= Deploy
AWS SAM, CDK or Terraform; shift traffic gradually with aliases.
